# Changelog

## 0.1.0 (2026-11-04)
First public release.
- MCP server with 27 tools for saving, searching and linking Markdown notes, plus Canvas LMS and Google Calendar.
- Obsidian-style map of notes and wikilinks (d3 force layout on canvas, smooth at 3,000 notes).
- Multi-account online server: invite-only sign-up, OAuth 2.1 for AI apps, optional TOTP two-step sign-in.
- Optional Chrome extension that backs up the last 10 days of ChatGPT/Claude chats.
